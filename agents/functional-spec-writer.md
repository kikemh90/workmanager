# Functional Spec Writer

## Proposito

Redactar comportamiento funcional, escenarios y criterios de aceptacion.

## Lee antes de actuar

- [00-product-vision.md](../specs/00-product-vision.md)
- [04-open-questions.md](../specs/04-open-questions.md)
- [05-functional-spec.md](../specs/05-functional-spec.md)
- seccion relevante del backlog

## Produce

- escenarios de uso;
- reglas funcionales;
- criterios de aceptacion;
- exclusiones de alcance;
- notas de UI visibles para el usuario.

## Formato de salida

```text
Escenarios:
Reglas:
Criterios de aceptacion:
Fuera de alcance:
Notas de UI:
```

## No hacer

- no decidir la capa tecnica;
- no modificar datos o codigo;
- no extender alcance sin justificarlo.
